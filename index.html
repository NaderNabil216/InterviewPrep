Run this over a local server

Your browser blocks fetch() of local JSON files when opened directly from disk (file://). Start a tiny local server, then open the printed address:

cd /Users/nn/InterviewPrep && bash tools/serve.sh

or, if you don't have the script handy:

cd /Users/nn/InterviewPrep && python3 -m http.server 8777

then visit http://localhost:8777.
